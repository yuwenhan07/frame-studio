# Windows 版隐私与本机数据

映框 Windows 版在本机读取、取色、排版和导出照片。程序没有账号、遥测、广告 SDK、上传照片或自动更新功能。窗口不允许外部网页、弹窗、下载与网络请求，渲染进程没有 Node.js 权限，通过隔离桥接调用有限的文件操作。

用户选择的文件仍可能位于网盘、网络盘或同步目录，系统及这些服务可能同步文件，这不由映框控制。

## 保存的数据

数据目录为 `%APPDATA%\FrameStudioWindows\`，包含 `Session.json`、`Session.previous.json`，必要时包含 `Recovery/` 损坏会话副本，以及 Electron 的本地运行缓存。会话记录原片路径、列表顺序、选中状态、逐照片修正和颜色、模板文字与样式、导出格式和尺寸。照片源文件不会复制进会话 JSON，导入时在内存中解码使用。数据没有额外加密；同一用户的其他程序、管理员和备份软件可能访问。请不要公开分享会话文件。

原片失联时保留编辑记录与来源路径。重新导入或恢复会话时，若检测到原路径文件的大小或修改时间变化，会清除旧的逐照片修正和颜色。此检测用于减少把旧编辑套到新照片的情况，不使用例行文件哈希；文件内容改变但大小和修改时间均未变时，无法据此识别。

## 导入与导出

导入仅接受本机选择或系统拖入的 JPEG、PNG、WebP、BMP。EXIF 读取限于品牌、型号、焦距、光圈、曝光、ISO、拍摄日期，不用于读取位置。预览与输出从解码像素绘制，导出再次编码 JPEG/PNG，不复制 GPS、序列号或原始 EXIF。显示在图上的拍摄信息、落款、地点等仍会成为可见内容；图像本身也可能含隐私。

导出拒绝覆盖导入原片及其别名；其他同名文件使用编号新建。移除列表项不删除照片或导出。退出时等待当前文件操作完成并保存会话；批量取消在当前照片完成后生效。

卸载安装版默认保留 AppData，免安装版也使用相同数据目录。彻底清理时先退出程序，再自行备份并删除上述目录，这会丢失本机编辑记录。发布包仅含程序、许可证和程序绘制的公开示例，不含开发者个人照片、凭据或编辑会话。

此说明基于源码与功能检查，不是对所有 Windows 版本的独立安全审计。

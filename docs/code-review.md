# 0.11.2 发布前代码与隐私审查

日期：2026-10-22。范围：全部手写 App/Core 源码、十五种模板的布局与渲染、检查程序、构建和素材转换脚本、固定品牌素材来源、内置示例、待推送文件与最终 App 压缩包。生成的品牌轮廓按固定素材来源、转换器和实际绘制检查核对，不逐点人工复刻 SVG。

结论：本轮未发现新增的阻断发布缺陷，也未发现凭据、个人照片、会话或本机开发目录进入待发布文件。导入、调色、排版和导出均在本机处理，运行代码没有照片上传、遥测、凭据读取或外部命令执行接口。这个结论来自源码审查、内容扫描和功能检查，不是独立安全认证或运行时网络抓包。

| 范围 | 结果与验证 |

- `swift run -c release FrameChecks`：345 项通过。

- `git diff --check` 通过；待发布文件内容扫描未发现访问凭据、个人照片名或绝对开发路径。
- 同一版本的本机界面在前序功能交付中已验证：十五种模板、接触印样移除、撕边效果与可选落款区。本轮重新运行上述自动检查与打包，没有重做完整系统「照片」图库拖拽操作。

## 保留的边界

- 本机会话与来源 App 交付的照片副本没有额外加密；照片副本可能保留来源 EXIF。移除列表不删除这些文件和历史调色记录，详见 [隐私说明](../PRIVACY.md)。
- 文件身份使用路径、大小与修改时间，不能区分刻意保留这些属性的替换文件。自动主色是启发式统计，支持人工修正。
- 来源 App 如果始终不兑现文件承诺，当前没有独立的接收超时/取消界面；不会因此删除原片。实际系统传输依赖来源 App 与系统状态。
- 撕边相纸有意裁切照片最外沿以呈现撕口；主体不额外调色。漫步票根仅在用户选择「填满裁切」时裁切构图。
- 发布二进制面向 Apple Silicon；macOS 14 为编译部署目标，本轮未在该最低版本或 Intel 实机运行。App 为 ad-hoc 签名，尚未 Apple 公证。

GitHub Actions 会在推送后对实际提交重跑核心检查、模型检查和打包。远程结果以该提交的 Actions 记录为准，正式 Release 需等待这些检查通过。

# 0.9.2 历史发布审查

日期：2026-10-17。范围：全部手写 App/Core 源码、检查程序、构建与品牌转换脚本、固定品牌素材、内置示例、待发布 Git 文件及 App 压缩包。生成的品牌路径核对来源清单、解析器和绘制检查。

结论：修复下列问题并完成本机验证后，未发现阻止本次公开发布的隐私问题。当前运行代码没有照片上传、遥测、凭据读取或外部命令执行路径；`Process` 仅用于独立进程会话回归测试。此结论基于人工源码检查、文件扫描和自动检查，并非独立安全认证、渗透测试或完整运行时网络抓包。

## 已修复的问题

| 发现 | 影响 | 处理与证据 |
| --- | --- | --- |
| 单张导出仅保护当前原片 | 保存到列表中另一张原片的路径时可能覆盖该文件 | 导出入口与实际写入均核对全部列表原片，规范化路径并解析符号链接；独立测试当前原片、另一张原片、链接别名及新目标，并逐字节核对原片 |
| 极小的正数 EXIF 快门值 | 倒数超出整数范围时转换崩溃 | 检查倒数有限性与整数范围；覆盖零、负值、NaN、无穷与极小正数，正常快门显示保持不变 |
| 图片与部分会话字段未统一限制本地 URL | 与离线处理边界不一致，异常会话可能打开外部链接 | 图片读写、导入队列和会话中的照片、Logo、导出位置统一验证本地文件 URL；拒绝远程目标的回归检查不发起网络请求 |
| 损坏会话可能包含极端样式数值 | 字号、透明度与数值格式化可能异常 | 解码时将所有样式数字限制到界面支持的范围，保留缺失字段迁移，增加极端数值检查 |
| 内置示例使用个人照片，README 含开发目录 | 发布会带出个人作品、拍摄信息和本机路径 | 以原创程序绘制风景替换示例；旧图仅保留在开发者本机；改成可移植构建说明；Git 排除 Examples、构建产物和 dist |
| 本地会话权限依赖默认值 | 同机其他普通用户的访问限制不够明确 | App 会话根目录使用 0700，主会话与备份使用 0600；新增权限检查。该措施不提供加密，也不阻止管理员或有相应权限的软件 |
| 会话错误测试在宽泛 catch 中断言 | 测试自身的断言错误可能被吞掉，产生假通过 | 将断言移到 catch 外并核对错误域；重跑检查，并在隔离副本中移除远程目录校验，确认检查能失败 |

发布构建还会重映射源文件路径并去除调试符号。最终可执行文件未检出开发者用户目录路径；包内仅包含程序、图标、程序绘制示例、说明和签名文件。

## 验证结果

在 Apple Silicon / macOS 27 / Swift 6.4 Command Line Tools 上运行：

- `swift run -c release FrameChecks`：194 项通过。
- `zsh scripts/check-selection.sh`：56 项选择与调色检查、22 项拖拽检查、29 项会话检查通过。
- 合计 301 项顶层检查；会话检查另启动独立进程验证恢复，不重复计入总数。
- 六种模板覆盖横竖图、方向、已知像素、取色、字体、品牌标志、原图完整性、尺寸、批量失败/取消和旧设置迁移。
- 隐私夹具先确认源文件确含测试 GPS，再分别导出 JPEG/PNG 并重新读取，确认未复制 GPS、机身序列号和原始拍摄时间。
- 生产 App 构建成功，`codesign --verify --deep --strict` 通过；二进制为 arm64，部署目标 14.0，仅链接 Apple 系统框架。
- 本机安装更新后正常启动，原有照片列表及整个会话内容保持一致。公开示例和文档图片来自程序绘制素材，未使用用户照片或桌面截图。

## 保留的边界

- 会话保存照片路径、用户文字和编辑值，来自「照片」的本机副本保留源文件 EXIF，均未额外加密。列表移除不会删除这些文件或偏好；详见 [隐私说明](../PRIVACY.md)。
- 云盘或「照片」App 可能自行同步/下载内容，属于系统或来源 App 行为。映框本身不上传照片。
- 自动取色是统计启发式，颜色占比为近似值，支持手动调整。
- 拖拽回归通过注入边界验证异步、乱序和失败。系统实际文件承诺拖拽在先前版本做过手动验证，本次未重跑完整「照片」图库交互；来源 App 永不兑现的承诺目前没有单独的超时取消界面。
- 公开二进制只提供 Apple Silicon；macOS 14 是编译部署目标，最低版本及 Intel 未在本次实际运行验证。
- App 使用 ad-hoc 签名，未 Apple 公证。商标和官方 SVG 保留品牌权利，MIT 仅覆盖原创代码与演示绘图，见 [素材说明](../THIRD_PARTY_NOTICES.md)。

GitHub Actions 配置会在推送和拉取请求中重跑检查与打包；远程 CI 结果独立于上述本机验证，以仓库实际运行记录为准。
